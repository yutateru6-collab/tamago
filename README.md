# tamago — こもれびの巣

スマホから離れるほど、小さな生き物が回復し、自分で探索し、住処をつくる「逆たまごっち」。使いすぎると、キャラも環境もはっきり荒れる。世界の中にはスマホやSNSを描かない。

## 現在：第1段階の動く試作

ホーム・探索・住処・記録、3段階のキャラと環境、探索2か所、制作3種類、帰還時の発見、ブラウザ内保存まで実装。

**端末全体の使用時間は未計測です。** 設定の「試作モード」で仮の2時間を入力します。タブを隠す・アプリを閉じるだけで報酬や罰を発生させません。画像は3状態の静止画で、作った家具が絵に追加される演出は次の段階です。

## 起動・確認

Node.js 24、npmを使用。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run check:runtime
npm run build
```

### 体験する順番

1. 住処 →「宝物の小さな棚」を作り始める。
2. ホーム右上の設定 →「離れた時間を試す」。
3.「住処に戻る」で、完成と拾い物の報告を見る。
4. 住処・記録を確認。リロードしても完成状態が残る。
5. 設定 →「使いすぎた状態を試す」で、キャラと住処の荒れ方を見る。

端末内保存のみ。ブラウザのデータ削除で消えます。アカウント、課金、同期、通知、ネイティブ計測、ストア公開は未実装です。
