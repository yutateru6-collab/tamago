# tamago — こもれびの巣

スマホから離れるほど、小さな生き物が回復し、自分で探索し、住処をつくる「逆たまごっち」。使いすぎると、キャラも環境もはっきり荒れる。世界の中にはスマホやSNSを描かない。

## 現在：全画面・30分のお約束つきWeb版

ホーム・探索・住処・記録、3段階のキャラと環境、探索2か所、制作3種類、帰還時の発見、ブラウザ内保存まで実装。

**端末全体の使用時間は未計測です。** 「30分、協力する」でお約束を始め、30分後に本人が「休めた」と確認したときだけ回復を記録します。画面を閉じただけでは回復・悪化しません。他のアプリを使ったかは検知しません。途中終了に罰はありません。開始・終了時刻を保存し、再読み込み後も続けられます。報酬とお約束の完了は同じ保存処理で更新し、二重加算を防ぎます。

- iPhoneの画面幅・セーフエリアに対応。通常は端末枠なし、`?preview=1` は従来の端末プレビュー。Safariのアドレスバーを強制的に隠すものではありません。ホーム画面に追加した場合は単独表示に対応。
- 元気・住処ゲージ、回復・悪化の説明、状態に応じたお願い。
- 3状態のイラストに座標を合わせた瞬き、木漏れ日・光の粒。動きを減らす設定を尊重。尻尾や耳の独立したアニメーションは未実装。
- 使いすぎは本人が30分ずつ記録。設定の2時間ボタンはデモ用。
- 絵の家具は状態ごとの固定描画。制作アイテムに合わせて絵へ追加する機能はまだありません。

## 起動・確認

Node.js 24、npmを使用。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run check:runtime
npm run build
```

### 体験する順番

1. 住処 →「宝物の小さな棚」を作り始める。
2. ホーム右上の設定 →「離れた時間を試す」。
3.「住処に戻る」で、完成と拾い物の報告を見る。
4. 住処・記録を確認。リロードしても完成状態が残る。
5. 設定 →「使いすぎた状態を試す」で、キャラと住処の荒れ方を見る。

端末内保存のみ。ブラウザのデータ削除で消えます。アカウント、課金、同期、通知、ネイティブ計測、ストア公開は未実装です。
