# tamago — こもれびの巣

スマホから離れるほど、小さな生き物が回復し、自分で探索し、住処をつくる「逆たまごっち」。使いすぎの自己申告で少し寂しくなった住処も、休息で修繕できます。世界の中にはスマホやSNSを描きません。

本番：https://tamago.itisnowornever271.workers.dev/

## 現在：全画面・30分のお約束つきWeb版

ホーム・探索・住処・記録、探索2か所、制作3種類、帰還時の発見、ブラウザ内保存まで実装。

**端末全体の使用時間は未計測です。** 「30分、協力する」でお約束を始め、30分後に本人が「休めた」と確認したときだけ回復を記録します。画面を閉じただけでは回復・悪化しません。他のアプリを使ったかは検知しません。途中終了に罰はありません。開始・終了時刻を保存し、再読み込み後も続けられます。報酬・結果の報告・お約束の完了は同じ保存処理で更新し、二重加算を防ぎます。

- iPhoneの画面幅・セーフエリアに対応。通常は端末枠なし、`?preview=1` は端末プレビュー。Safariのアドレスバーを強制的に隠すものではありません。
- 現行の工房の青い子と原画動画を維持。元気・回復中・疲れで映像は共通、状態は表示とゲージで区別。再生・停止の保存と省モーションに対応。追加キャラや専用動作は未実装です。
- 棚・宝物・鉢植え・寝床は独立レイヤー。制作の進捗や住処の傷みに合わせて変化し、休息で修繕できます。完成した実績や材料は失われません。
- 家具の見本、必要な材料、途中の進み具合を表示。材料不足から探索へ、制作中から休息へ進めます。
- 休息後の報告に実際の制作・修繕・材料の変化を保存。30分では完成しない場合も、途中までの成果が分かります。
- 使いすぎは本人が30分ずつ記録。設定の2時間ボタンはデモ用で、保存データにも反映されます。

## 起動・確認

Node.js 24、npmを使用。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run check:runtime
npm run build
npm run test:sites
npm run test:app
```

### 最初の体験

1. ホームの「集めた木で、小さな棚をつくろう」から制作を選びます。
2. 保存後にホームへ戻り、「30分、協力する」。画面を閉じて構いません。
3. 30分後に「休めた」を伝えると、元気が十分なら棚が半分まで進みます。回復や修繕が先に必要な場合は、そちらを優先します。
4. 帰還報告と住処の進み具合を確認。リロードしても保存されます。
5. 次のお約束は好きなときに。急いで開き続ける必要はありません。

すぐに変化を確認する場合は、設定の「変化をすぐに試す」を使用します。デモも同じ保存状態を変更します。

端末内保存のみ。ブラウザのデータ削除で消えます。アカウント、課金、同期、通知、ネイティブ計測、ストア公開は未実装です。
