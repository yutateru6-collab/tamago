# 休んだあとの、お楽しみとキャラクター試用

2026-09-19。公開先: https://tamago.itisnowornever271.workers.dev/

## 使い方

- 合計30分ごとに「木の実のおやつ」1回、60分ごとに「こもれびのお茶」1回、120分ごとに「水辺のピクニック」1回。
- 休息の30分を「休めた」と報告すると、3種類に共通で加算。回復やお手入れ中でも加算する。120分で、おやつ4回・お茶2回・ピクニック1回がたまる。
- ホームに条件・残り時間・未使用の回数を表示。楽しみを選び、器やお弁当を用意するボタンを押すと、1回分を使って思い出を記録する。短い小物の演出と文章のイベントであり、キャラ専用の食事動画ではない。
- 途中で閉じた場合は未使用のまま。確定後は再読み込みしても消費・思い出が残る。保存できなければ成功表示せず、同じ画面で再試行できる。
- 30分ずつ分けて休める。回数に期限はなく、使いすぎの報告でも減らない。休息の時間を取り消したり、制作時間として二重に使う仕組みではない。イベント自体で元気・材料・制作をさらに加算しない。

## 保存と拡張

Worldの省略可能フィールド restEvents に確認済み minutes と各イベントの enjoyed 回数を保存。既存セーブを維持し、この機能追加後の確認から数える。過去の推測時間から遡及付与しない。追加前に開始した休息でも、追加後に完了報告すれば対象。

獲得回数は floor(minutes / requiredMinutes)、利用可能回数はそこから enjoyed を引く。completeQuiet の保存トランザクションで時間を加算する。Web Lock と revision に加え、シートを開いた時点の enjoyed を照合し、連打・他タブ・古い画面からの二重消費を拒否する。表示・動画再生だけでは進まない。

src/domain/restEvents.ts の REST_EVENTS で時間・名前・説明・結果を定義。描画は共通コンポーネント。イベント用画像は /art/event-ID.webp。新しい報酬のルールが必要な場合はドメインの変更と検証も必要。

## 開発者モード

- 通常とは別のsessionStorage。30/60/120分プリセットと、本物の完了処理を使う「30分の休息を完了する」で試す。2時間デモは従来エンジン用で、お楽しみは付与しない。
- 「木の実色の子」「こもれびのフクロウ」の2体を追加。通常版は工房の青い子。選択は tamago.sandbox.companion.v1 に保存し、状態プリセット・画面遷移・再読み込みをまたいで保持。
- ホーム・探索・住処・記録・休息・イベントに同じ選択を反映。家具の位置と背景・傷みも共通。通常へ戻ると青い子に戻り、個人の進捗は変わらない。
- 追加2体の動きは透明画像の穏やかな揺れ。省モーションでは静止。元の原画動画と同じ豊富な動作がある、という意味ではない。

## 確認項目

30/60/120分と反復、早期完了拒否、キャンセル・未知時間・利用報告での非加算、回復中の加算、利用・保留・再読み込み、保存失敗、別タブの古い利用要求、旧セーブ、3キャラの全画面一致と通常データの分離。Chromium/WebKit・320/390/430pxと原画動画の自然再生を確認。

素材の生成モード・原本・プロンプトは art-prompts.md。元のキャラ画像・動画は変更しない。
