# 住処の変化とお手入れ

スマホから離れた時間で暮らしが育つ。Web版では明示的な自己申告のみを記録し、他アプリの使用、画面を閉じた時間、キャンセルを悪化の根拠にしない。

## 最初の循環
- 木2個で棚を作り始める。30分のお約束を確認すると棚の下段ができ、60分で完成する。
- 探索の回数に応じて棚の宝物が最大3個まで増える。庭の完成で鉢植え、寝床の完成でハンモックを表示する。
- 使いすぎの自己申告30分につき傷み4.5。一日最大25。記録した実日時の日本時間の日付で区切り、時計の巻き戻りで上限を再開しない。
- 傷み20で花と葉がしおれ、25ごとに宝物が一つ減る。45で家具が傷み、75で家具を表示しなくなる。光も少しずつ落ち着く。
- 完成済みのID、材料、思い出は消さない。休んで元気が戻ったら、一分につき傷み0.75を修繕する。修繕中は制作・探索を同時に進めず、残りの時間を次の作業に渡す。材料の追加消費はない。
- 修繕しても当日の減少上限はリセットしない。旧保存データは傷み0として読み込み、次回記録から追加フィールドを保存する。

数値は初期調整。元気の既存ルールは維持し、住処の悪化量のみ日次上限で制限する。OS連携による実計測は未実装。

## 描画
承認済みの原画動画は変更しない。右側の家具領域に家具なしの背景を重ね、棚・宝物・鉢植え・寝床を独立した透過素材で描く。動画の再生状態は進行に影響しない。

画像はbuilt-in image_genで原画を参照して生成。`public/art/home-empty.jpg`、`home-shelf.webp`、`home-treasure.webp`、`home-plant.webp`、`home-plant-wilt.webp`、`home-hammock.webp`。配信時の圧縮・縮小はffmpegを使用し、透過素材のalphaを保持する。
