# 休息・制作・探索をつなぐ体験

2026-09-19。キャラは現行の工房の青い子と原画動画のまま。添付された別キャラの設定画は、差し替え・追加・3D化の承認ではありません。

本番確認先：https://tamago.itisnowornever271.workers.dev/

## この変更の範囲

- ホームに最初の棚への案内。初期の木2個で作り始められます。探索から始める自由も維持します。
- 住処に既存家具の見本、材料の所持数と必要数、制作の保存済み進捗を表示。確保済み材料を再要求しません。
- 材料不足から探索へ移動。探索先ごとに見つかる材料の個数を表示。探索途中の行き先変更を止める既存仕様は維持します。
- 制作開始と行き先変更は、保存に成功してからホームに戻ります。制作中の住処画面・選択した探索先からも30分のお約束へ進めます。
- 帰還報告は実際の前後の状態を比較。元気・心地よさ、制作の途中経過と完成、修繕、探索、材料を既存Memory.detailに記録します。旧データを変更せず、今後完了するお約束から対象です。
- 進行処理・調整値・材料・保存形式は変更しません。お約束の目的ラベルだけ、既存の作業開始しきい値に合わせます。

## 境界

30分経過だけでは報酬を加算しません。「休めた」の自己申告と保存が必要です。報告生成は読み取り専用です。元気回復のみで制作が進まない場合、完成を捏造しません。修繕優先・材料の再徴収なし・キャンセル無罰・一日の傷み上限を維持します。

## 確認項目

`npm test`、`npm run check:runtime`、`npm run build`、`npm run test:sites`、`npm run test:app`。

追加のjourney.spec.tsは既存app.spec.tsとともにChromium / WebKitで実行。30分の途中制作、報告の再読み込み、材料不足から探索、キャンセル、保存失敗時の画面維持、320 / 390 / 430pxの画面を確認します。スクリーンショットは既存のiphone-visual-review成果物へ保存します。本番はworkflow_dispatchのapp_urlに公開URLを指定して別途確認します。
