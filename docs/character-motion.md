# 原画アニメの接続・第1段階

対象は工房の青い子。進行ルール、保存形式、30分の自己申告方式は変更しない。

| 状態 | 表示 | 次に必要な素材 |
| --- | --- | --- |
| thriving（元気） | 承認済み原画の10秒MP4。呼吸・瞬き・耳・尻尾 | 現在の待機素材を利用 |
| recovering（回復中） | 承認済み原画の共通待機動画＋回復中の状態表示 | 同じ原画タッチの回復中ループ |
| weary（疲れ） | 承認済み原画の共通待機動画＋疲れの状態表示 | 同じ原画タッチの休息ループ |
| 制作 | ホームに制作名と記録済み進捗を表示 | 工具を扱う短い動作 |
| 探索 | ホームに行き先と記録済み進捗を表示 | 出発・帰還の短い動作 |
| 完成 | 既存の帰還報告とホームの制作済み一覧 | 背景と分離した家具素材 |

制作・探索の表示は保存された進捗を示す。動画再生で時間や報酬は加算しない。
休息優先の表示は進行処理と同じ workThreshold を使う。住処が荒れていても元気が十分なら作業できる既存ルールを維持する。
動画失敗時は元画像を表示。省モーション設定・明示的な再生／停止の保存・非表示時の停止に対応する。
読み込み失敗後も「動きをもう一度読み込む」から動画を再取得できる。明示的な再生はユーザーの操作中に表示してから開始し、設定更新の後片付けでは進行中の再生を止めない。自動再生と手動再生は同じ処理を共有し、再生中の重複要求を避ける。動画読み込みエラーと自動再生の拒否を再現したChromium/WebKitのテストで、手動再生・再試行・進捗の不変を確認する。

元気な姿以外の新規動作、3体の選択、Rive、家具の背景への配置、OS計測はこの変更には含まれない。
元気な原画動画は、このスレッドで承認された outputs/tamago-friends/workshop/original-art-idle.mp4 に由来する。

耳・尻尾の旧SVG変形と上塗りのまぶたは全状態から廃止。初期状態・休息画面でも原画動画を使う。専用素材ができるまでは映像を共通とし、状態の違いはラベルとゲージで示す。

## 公開環境の動画配信

Cloudflareの静的配信で `Range: bytes=3749-` に全動画の200応答が返り、WebKitで省モーションから手動再生した際に読み込みエラーが発生した。`src/server/video-worker.js` が元動画のURLだけを受け持ち、要求された部分を206応答で返す。元動画・元画像・保護されたSites用Workerは変更しない。

一部のWebKitメディア実装はループ先頭への移動時に再生を停止する。seeked時に、ユーザーが再生を選び、ページが表示され、読み込みエラーがない場合だけ再開する。実際に1周以上再生し、エラーがなく再生を続けていることをテストする。停止・非表示・省モーションの既定では再開しない。

配信元のETagと条件付きリクエストを維持し、範囲外は416、不明・複数範囲は動画全体を返す。バッファ処理はこの元動画だけに限定し、読み込みを1 MiBで打ち切る。Assets binding内部ではContent-Lengthが省略される場合があるため、上限内で実際に読んだ長さを使う。動画全体と部分取得の内容一致を検証する。`npm run check:worker` でWranglerから生成した型を使い、`npm test` で配信処理を確認する。ブラウザテストはローカルのWranglerと公開URLの両方で動かす。
