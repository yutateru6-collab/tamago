# 段階計画

## 1. 体験と土台（今回）
4画面、明示的な仮時間入力、回復/悪化、探索/制作、帰還報告、端末内保存。進行処理とUIを分離し、重複計上と保存のテストを用意する。

## 2. OS計測の実機検証（次の最優先）
iPhoneを先行候補として、Family Controlsの個人認証とDevice Activityの閾値通知を小さな検証アプリで確認。配布用entitlement申請、拒否/取消時の挙動を確認する。AndroidはUsageStats権限と端末ごとのイベント欠損を検証する。

合格条件：画面を閉じていても必要な指標が取得できる／他アプリ使用を休息と誤認しない／権限不明なら停止／再起動・時刻変更で二重報酬なし。取得できる粒度に合わせて「休息」の定義を確定してからUIへ接続する。汎用ブラウザ版だけでの達成を前提にしない。

## 3. 世界を生活させる
背景、家具、キャラ、汚れ、光をレイヤー化。完成した棚などを正しい位置に追加する。探索中、制作中、休息中の短いアニメーション。キャラ5体への展開は共通インターフェイスで行う。

## 4. 継続性と公開準備
実使用の試験から悪化・回復速度を調整。オンボーディング、権限の再案内、必要用途の除外、文字サイズ、動きを減らす設定、データ移行と復旧を整える。ストア公開前にプライバシー説明、実機電池消費、支援技術を検証する。

各段階を個別コミット/PRで進め、計測・ルール・アートを一度に変更しない。新機能より先にその段階の合格条件を満たす。
